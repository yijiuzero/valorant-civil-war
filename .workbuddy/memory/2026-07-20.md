# 2026-07-20 工作日志

## 项目代码审查与优化

对 VALORANT 战术工具集 V3.4.4 进行了全面的代码审查，从代码质量、性能、CSS、安全四个维度识别了优化机会，并完成了一轮高/中优先级修复。

### 已修复

1. **CSS Bug** — styles.css 420px 断点中 `.ac-btn` 重复定义（28px → 44px 覆盖），删除了无效规则
2. **死代码清理** — 删除未使用的 `.teamsplit-rank-badge` 样式（20行）
3. **CSS 声明合并** — body 两个声明块合并为1个；768px 两个 @media 块合并
4. **硬编码颜色变量化** — `.module-title` / `.module-sub` 从硬编码色值改为 CSS 变量（`--accent` / `--text-dim`）
5. **常量提取** — `app-data.js` 新增 `VALORANT_API` 常量；app.js 和 teamsplit.js 的 API URL 统一引用
6. **CSS 角色颜色变量化** — 新增 `--role-duelist/inimiator/controller/sentinel` 四个 CSS 变量
7. **重复函数提取** — teamsplit.js 中 `teamRow` 从两处内联定义提取为模块级函数
8. **var → const/let** — teamsplit.js 全部 70+ 个 `var` 替换为 `const`（2 个 for 循环 i 用 `let`）

### 第二轮优化（性能与增量更新）

9. **动画 setInterval → requestAnimationFrame** — drawMaps 和 randomAgent 改为 rAF + 帧节流(80ms)，后台标签页自动暂停、省电
10. **DOM 缓存** — nav-item/content-layer/mainArea 在 init() 时缓存为变量，switchModule 不再全量 querySelectorAll
11. **模块懒加载** — 取消 init() 中的 renderMapCards/renderAgents 预渲染，改为首次切模块时才渲染
12. **Realtime 增量更新** — handlePlayersChanged 改用 Supabase payload (INSERT/UPDATE/DELETE) 增量更新 currentPlayers 数组，仅在数据不一致时 fallback 全量查询

### 第三轮：内鬼模式 V1 (新增功能)

**新增文件：**
- `spy-mode.js` (~200行) — 内鬼模式核心：Supabase spy_state 同步、身份分配(Fisher-Yates)、四阶段视图控制器
- `init-spy-db.sql` — Supabase 初始化脚本（rooms 表新增 spy_state JSONB 列）

**修改文件：**
- `index.html` — 内鬼模式面板（4个子视图：初始化/分配/游戏/揭晓）+ 脚本加载
- `app.js` — 模块切换兼容
- `app-data.js` — 12条内鬼任务卡数据 + window.spyTasks 导出
- `styles.css` — ~100行内鬼模式样式（含响应式）
- `teamsplit.js` — 桥接函数(openSpyMode/closeSpyMode)、showTeamsplitView 隐藏间谍面板、ts_spy_teams 独立存储

**功能设计：**
- 依托现有分队房间系统；每队随机分配1名内鬼
- 内鬼身份仅本人可见（Supabase 信任制存储）
- 内鬼获得随机"破坏任务卡"（12条预定义任务，避免两队相同）
- 流程：分队完成 → 开启内鬼模式 → 分配身份 → 游戏中(内鬼面板) → 房主揭晓
- 安全模型：信任制（不防网络抓包，适合好友局）
- 已知限制：MVP 无投票机制，仅房主揭晓；后续可迭代
