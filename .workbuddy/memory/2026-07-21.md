- ⚠️ 关键提醒：Supabase 后台默认 Minimum password length = 6，若不改，4–5 位密码前端放行但服务端仍会拒绝（signUp/signIn 报错）。需在 Supabase 控制台 Auth→Providers→Email 把该值调到 ≤4。已在 PROJECT_CONTEXT.md 版本历史与待办勾选处标注。
- 教训：跨「前端校验 + 第三方服务策略」的需求，务必同步检查服务端（Supabase/后端）的对应限制，否则会出现前端放行、后端拒收的割裂。
